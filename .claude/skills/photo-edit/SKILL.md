사진 보정을 위한 재사용 가능한 CLI 스크립트가 `scripts/edit_photo.py`에 이미 준비되어 있습니다. 사용자가 보정/리사이즈/비율 크롭을 요청하면 이 스크립트를 그대로 실행하세요 — 새로 Pillow 코드를 작성하지 않습니다.

## 핵심 원칙: 원본을 절대 건드리지 않는다

이 스크립트는 기본적으로 입력 파일/폴더 옆에 `edited`라는 **새 폴더**를 만들어 결과를 저장합니다. 원본을 덮어쓰는 옵션은 없습니다. 사용자가 저장 위치를 지정하면 `--out-dir`로 바꿀 수 있지만, 그 경우에도 입력 경로와 같은 폴더를 가리키지 않도록 주의하세요.

## 기능과 옵션

| 옵션 | 의미 | 기본값 |
|---|---|---|
| `입력` (위치 인자) | 이미지 파일 1개 또는 이미지가 든 폴더 | 필수 |
| `--out-dir` | 결과 저장 폴더 | 입력 옆 `edited/` |
| `--brightness` | 밝기 배율 (1.0=원본, 1.2=20% 밝게) | 1.0 |
| `--contrast` | 대비 배율 (1.0=원본) | 1.0 |
| `--hue` | 색조 회전 각도(도 단위, -180~180) | 0 |
| `--width`, `--height` | 최종 크기(px). 하나만 주면 비율 유지, 둘 다 주면 정확히 그 크기로 리사이즈 | 없음(크기 유지) |
| `--ratio` | `1:1` / `4:5` / `9:16` 중 하나로 중앙 크롭 | 없음 |
| `--recursive` | 폴더 입력 시 하위 폴더까지 처리 | 꺼짐 |

처리 순서는 **밝기/대비/색조 보정 → 비율 크롭 → 리사이즈** 순으로 고정되어 있습니다(크롭 전에 리사이즈하면 비율 계산이 어긋나기 때문).

## 사용 예시

```bash
# 사진 한 장: 살짝 밝게 + 인스타 정사각형 비율로 크롭
python scripts/edit_photo.py photo.jpg --brightness 1.15 --ratio 1:1

# 폴더 전체를 4:5 비율로 크롭하고 1080 너비로 리사이즈, 결과는 지정한 폴더에 저장
python scripts/edit_photo.py ./photos --ratio 4:5 --width 1080 --out-dir ./photos_insta

# 색조만 살짝 틀어보기 (예: 30도 회전)
python scripts/edit_photo.py photo.jpg --hue 30
```

## 작업 절차

1. 사용자의 요청에서 입력(파일/폴더), 원하는 보정값(밝기/대비/색조), 크기나 비율을 파악한다. 수치가 애매하면("조금 밝게") 1.1~1.2 같은 무난한 값으로 해석하고, 결과를 보여줄 때 어떤 값을 썼는지 밝힌다.
2. 위 스크립트를 해당 옵션으로 실행한다.
3. 출력 로그(`saved: ...`)로 몇 장이 처리됐는지, 어디에 저장됐는지 확인한다.
4. 가능하면 결과 이미지 중 1장을 `Read`로 열어 의도한 보정이 반영됐는지 확인한다(사용자가 확인 생략을 요청한 경우는 생략).
5. 결과를 표로 보고한다 — 처리한 장 수, 적용한 옵션, 저장 위치.

## 지원 포맷

`.jpg`, `.jpeg`, `.png`, `.webp`, `.bmp`. 폴더 모드는 기본적으로 최상위 폴더만 보고, 하위 폴더까지 보려면 `--recursive`를 쓴다.

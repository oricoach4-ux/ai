이 프로젝트에는 이미 완성된 카드뉴스 생성기가 `C:\Users\SBS\Desktop\AI\카드뉴스\` 폴더에 있습니다. 사용자가 카드뉴스를 요청하면 새로 코드를 짜지 말고, 이 스크립트의 설정 파일만 바꿔서 실행하세요.

## 구성 파일

- `generate_cards.py` — 실제 이미지를 그리는 재사용 스크립트. **수정하지 않는다** (기능 자체를 바꿔달라는 요청이 아닌 한).
- `cards_config.json` — 매번 바뀌는 내용(주제, 문구, 색상, 크기, 파일명 규칙)을 담는 설정 파일. **매 요청마다 이 파일만 고쳐 쓴다.**
- `cards_config.example.json` — 설정 파일 구조의 예시/백업용. 구조가 궁금하면 참고한다.

## 설정 파일(cards_config.json) 구조

```json
{
  "size": [1080, 1080],
  "output_dir": ".",
  "topic": "주제명",
  "filename_pattern": "{topic}-{i}.png",
  "footer_label": "화면 하단에 표시될 라벨",
  "color_palettes": [[[r,g,b],[r,g,b]], ...],
  "quotes": [
    { "text": "본문. 줄바꿈은 \\n으로 직접 넣는다.", "author": "출처/연도 등 작은 글씨" }
  ]
}
```

- **파일명**: `{topic}-{i}.png` 형식으로 자동 생성된다 (예: 주제가 "과학발전사"면 `과학발전사-1.png`, `과학발전사-2.png` ...). `topic` 필드만 바꾸면 전체 파일명이 따라간다.
- **색상**: `quotes` 항목마다 색을 직접 안 적어도 `color_palettes` 목록에서 카드 순서대로 자동 순환해서 쓴다. 특정 카드만 다른 팔레트를 쓰고 싶으면 `"palette": <인덱스>`를 추가하고, 완전히 새로운 색이 필요하면 `"colors": [[r,g,b],[r,g,b]]`를 직접 넣는다(우선순위: `colors` > `palette` > 자동 순환).
- **크기**: 기본 1080×1080(정사각, 인스타그램 피드용). 세로형이 필요하면 `size`를 `[1080, 1350]` 등으로 바꾸거나 실행 시 `--size 1080x1350`으로 덮어쓴다.

## 작업 절차

사용자가 "OOO 주제로 N개 만들어줘"라고 하면:

1. **내용 준비**: 주제에 맞는 N개의 문구를 직접 작성한다.
   - 명언류 요청이면 실존 인물의 실제 명언 + 정확한 출처를 쓴다. 지어내지 않는다.
   - 역사/사실 정보 카드면 검증 가능한 사실만 쓰고, `author` 필드를 "인물 · 연도, 핵심 키워드" 식으로 활용해 부가 정보를 함께 보여준다.
   - 한 줄이 너무 길면 자연스러운 의미 단위로 `\n`을 넣어준다. 완벽하게 안 맞아도 스크립트가 폭에 맞춰 자동으로 줄바꿈/폰트 축소를 해주니 너무 신경 쓰지 않아도 된다.
2. **`cards_config.json` 수정**: `topic`, `footer_label`, `quotes`를 새 내용으로 교체한다. `color_palettes`, `size`, `filename_pattern`은 사용자가 따로 요청하지 않으면 그대로 둔다.
3. **실행**: 프로젝트 루트가 아니라 `카드뉴스` 폴더에서 `python generate_cards.py`를 실행한다. (크기/주제를 일시적으로만 바꾸고 싶으면 `--size`, `--topic`, `--out-dir` 플래그로 설정 파일을 건드리지 않고 덮어쓸 수 있다.)
4. **검증**: 생성된 PNG 중 최소 1~2장을 Read 도구로 직접 열어 텍스트가 박스를 벗어나지 않는지, 색상이 의도대로 적용됐는지 눈으로 확인한다. 확인 없이 "완료"라고 보고하지 않는다.
5. **보고**: 결과를 표로 정리해서 보여준다 — 카드별 내용 요약과 색상/팔레트를 한 줄씩. 기존에 만들어둔 다른 주제의 카드(`오늘의명언-*.png` 등)는 요청받지 않는 한 지우지 않는다.

## 주의할 점

- 터미널(`ls`, `python` 실행 결과)에 한글 경로/파일명이 깨져 보이는 것은 콘솔 코드페이지 표시 문제일 뿐, 실제 파일은 정상이다. `ls -la`로 폴더를 다시 확인하면 한글이 올바르게 보인다 — 당황해서 파일을 지우거나 재생성하지 않는다.
- 폰트는 `C:/Windows/Fonts/malgun.ttf`(본문), `malgunbd.ttf`(굵게)를 이미 쓰고 있다. 다른 폰트가 필요하다는 요청이 없는 한 바꾸지 않는다.
- `generate_cards.py` 자체의 레이아웃/디자인을 바꿔달라는 요청(예: 색상 변수화, 파일명 규칙 변경)은 설정 파일이 아니라 스크립트 코드를 수정해야 하는 작업이다 — 이런 요청과 "내용만 바꿔서 카드뉴스 만들어줘"를 구분한다.

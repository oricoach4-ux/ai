웹 검색으로 최신 자료를 모으고, [[card-maker]] 스킬의 `cards_config.json`에 바로 넣을 수 있는 형태로 가공하는 스킬입니다. "검색"과 "카드뉴스 제작"을 분리해서, 조사 단계에서는 정확성에, 제작 단계에서는 디자인에 집중할 수 있게 합니다.

## 왜 검색부터 하는가

카드뉴스는 한 장에 들어가는 정보가 매우 짧기 때문에, 압축하는 과정에서 날짜·수치·고유명사가 틀리기 쉽습니다. 특히 "최신"을 요구하는 주제(뉴스, 트렌드, 통계, 가격, 순위 등)는 모델이 이미 알고 있는 지식만으로 답하면 오래된 정보일 위험이 큽니다. 그래서 바로 카드를 쓰지 않고, 먼저 검색으로 사실을 확인·갱신하는 단계를 거칩니다.

## 작업 절차

1. **검색**: WebSearch로 주제에 대한 최신 자료를 찾는다. "최신"이 핵심인 주제는 검색어에 올해 연도나 "최근", "최신" 같은 표현을 넣어 오래된 결과가 섞이는 것을 줄인다.
2. **교차 확인**: 수치·날짜·고유명사처럼 틀리면 눈에 띄는 정보는 가능하면 서로 다른 출처 2곳 이상에서 확인한다. 출처마다 내용이 다르면 추측으로 하나를 고르지 말고 사용자에게 알린다.
3. **카드 단위로 압축**: 찾은 내용을 각각 1~3줄짜리 짧고 명확한 문장으로 압축한다. 카드 한 장에 들어갈 분량(제목처럼 핵심 메시지 하나)을 넘지 않도록 한다 — 배경 설명은 덜어내고 핵심만 남긴다.
4. **card-maker 형식으로 출력**: 결과를 바로 `cards_config.json`의 `quotes` 배열에 붙여넣을 수 있는 JSON 조각으로 정리한다.

   ```json
   { "text": "압축된 핵심 문장 (필요하면 \\n으로 줄바꿈)", "author": "출처명 · 날짜" }
   ```

   `author` 필드는 명언의 "말한 사람" 자리를 빌려 "출처 · 날짜"를 적는 용도로 쓴다 (예: "OO일보 · 2026.10", "통계청 · 2026년 발표").

5. **사용자에게 보고**: 각 카드 후보를 표로 보여준다 — 번호 / 핵심 내용 요약 / 출처 / 발행일. 원문 URL은 표 아래에 목록으로 남겨서 나중에 검증할 수 있게 한다.
6. **다음 단계 안내**: 사용자가 내용에 동의하면, 이 결과를 그대로 [[card-maker]] 스킬의 `cards_config.json`에 반영하고 `generate_cards.py`를 실행하는 흐름으로 이어간다. 검색정리기 스스로 이미지를 만들지는 않는다 — 내용 조사와 정리까지가 역할이다.

## 지켜야 할 것

- 검색 결과에 없는 내용을 지어내지 않는다. 자료가 부족하면 "확인된 정보가 적다"고 사용자에게 솔직히 말한다.
- 광고성/출처 불명 사이트보다 1차 출처(공식 발표, 주요 언론, 공식 통계)를 우선한다.
- 카드 문구는 원문을 그대로 베끼지 말고, 사실관계는 유지한 채 카드뉴스 톤(짧고 명확한 문장)으로 다시 쓴다.

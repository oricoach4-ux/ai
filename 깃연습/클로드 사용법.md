# 클로드 사용법

## 1. 클로드란?
클로드(Claude)는 Anthropic에서 만든 AI 어시스턴트입니다. 대화형으로 질문에 답하고, 글을 작성하고, 코드를 짜고, 파일을 분석하는 등 다양한 작업을 도와줍니다.

## 2. 기본 사용 방법
- **질문하기**: 궁금한 내용을 자연스러운 문장으로 입력하면 됩니다.
- **맥락 유지**: 같은 대화 안에서는 이전 내용을 기억하므로, 이어서 질문할 수 있습니다.
- **구체적으로 요청**: "이 코드를 고쳐줘"보다 "이 함수에서 에러 처리 부분만 고쳐줘"처럼 구체적으로 요청하면 더 정확한 답을 받을 수 있습니다.

## 3. Claude Code (터미널용 클로드)
- 코드 작성, 파일 수정, 터미널 명령 실행, git 연동 등을 직접 수행할 수 있습니다.
- 주요 기능:
  - 파일 읽기/쓰기/수정 (`Read`, `Edit`, `Write`)
  - 터미널 명령 실행 (`Bash`, `PowerShell`)
  - 코드 검색 (`Grep`, `Glob`)
  - git 저장소 연동 및 GitHub CLI(`gh`) 사용

## 4. 효과적으로 활용하는 팁
1. 원하는 결과물을 먼저 명확히 설명한다.
2. 복잡한 작업은 단계별로 나눠서 요청한다.
3. 결과물을 확인하고 피드백을 주면 더 정교하게 다듬어진다.
4. 반복 작업은 스킬(Skill)이나 스크립트로 저장해두면 다음에 재사용하기 편하다.

## 5. 주의할 점
- 민감한 정보(비밀번호, 토큰 등)는 대화나 코드에 직접 노출하지 않는다.
- 중요한 작업(삭제, push, 배포 등)은 실행 전에 한 번 더 확인한다.

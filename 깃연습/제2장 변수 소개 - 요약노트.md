## 1. 프로그램의 기본 동작 흐름
```
입력(외부 데이터 받기) → 처리(데이터 가공) → 출력(화면에 결과 표시)
```

## 2. 변수란?
- **변수(variable)**: 값을 저장하는 공간. "값을 담는 상자"로 생각하면 된다.
- 파이썬에서는 선언 없이 바로 대입해서 변수를 만든다.

```python
x = 100        # 변수 x 생성, 100 저장
x = 200        # 같은 변수에 다른 값을 다시 저장 가능
print(x)       # 200
```

```python
x = 100
y = 200
sum = x + y
print(sum)     # 300
```

- 변수에는 **정수뿐 아니라 문자열도** 저장 가능하다.
```python
name = "홍길동"
address = "서울시 종로구 1번지"
```

## 3. 변수 이름 규칙
| 규칙 | 설명 |
|---|---|
| 의미 있는 이름 사용 | 변수 이름만 보고 역할을 알 수 있게 짓는다 |
| 대소문자 구분 | `Score`와 `score`는 서로 다른 변수로 취급 |
| 구성 문자 | 영문자, 숫자, 밑줄(`_`)만 사용 가능 |
| 공백 금지 | 중간에 공백 불가 → 단어 구분은 밑줄(`_`)로 |
| 시작 문자 | 영문 알파벳 또는 밑줄(`_`)로 시작해야 함 (숫자로 시작 불가) |
| 기호 금지 | `#` 등의 기호는 사용 불가 |

**예시**
| 변수명 | 가능 여부 | 이유 |
|---|---|---|
| `sum` | ✅ | 영문자로 시작 |
| `_count` | ✅ | 밑줄로 시작 가능 |
| `number_of_pictures` | ✅ | 중간에 숫자/밑줄 가능 (맨 처음 숫자만 금지) |
| `King3` | ✅ | 맨 처음이 아니면 숫자 가능 |
| `2nd_base` | ❌ | 숫자로 시작할 수 없음 |
| `money#` | ❌ | `#` 기호 사용 불가 |

**낙타체(camelCase)**: 첫 글자는 소문자, 이후 각 단어의 첫 글자는 대문자로 표기
```
myNewCar
```

## 6. 변수를 쓰는 이유 — 터틀 그래픽 예제
반지름이 100인 원 3개를 그리는 코드에서, 반지름을 50으로 바꾸고 싶다면:

- **변수를 안 쓴 경우**: `t.circle(100)`이 나온 모든 곳을 일일이 찾아 수정해야 함
- **변수를 쓴 경우**: `radius = 100`을 `radius = 50`으로 **한 군데만** 고치면 끝

```python
import turtle
t = turtle.Turtle()
t.shape("turtle")
radius = 50
t.circle(radius)   # 반지름이 50인 원이 그려짐
t.fd(30)
t.circle(radius)
t.fd(30)
t.circle(radius)
```

➡️ **핵심**: 같은 값이 여러 곳에 쓰일 때 변수로 관리하면 유지보수가 훨씬 쉬워진다.

## 7. input()으로 사용자 입력 받기
입력값은 기본적으로 **문자열**이므로, 숫자 계산이 필요하면 `int()`로 변환해야 한다.

```python
x = int(input("첫 번째 정수를 입력하시오: "))
y = int(input("두 번째 정수를 입력하시오: "))
sum = x + y
print(x, "과", y, "의 합은", sum, "입니다.")
```

```python
name = input("이름을 입력하시오: ")
print(name, "씨, 안녕하세요?")
print("파이썬에 오신 것을 환영합니다.")
```

## 8. 응용 예제 — 터틀로 집 모양 그리기
사용자 입력값(`size`)을 변수로 받아 도형의 크기를 그 즉시 결정한다.

```python
import turtle
t = turtle.Turtle()
t.shape("turtle")
size = int(input("집의 크기는 얼마로 할까요? "))
t.forward(size)
t.right(90)
t.forward(size)
t.right(90)
t.forward(size)
t.right(90)
t.forward(size)
t.left(120)
t.forward(size)
t.left(120)
t.forward(size)
```

## 9. 응용 예제 — 변수로 기사(문장) 자동 생성
여러 개의 `input()`으로 받은 값을 변수에 저장한 뒤, 문자열과 조합해 완성된 문장을 출력한다.

```python
stadium = input("경기장은 어디입니까?")
winner  = input("이긴팀은 어디입니까")
loser   = input("진팀은 어디입니까?")
vip     = input("우수선수는 누구입니까?")
score   = input("스코어는 몇대몇입니까?")

print("===========================================")
print("오늘", stadium, "에서 야구 경기가 열렸습니다.")
print(winner, "과", loser, "은 치열한 공방전을 펼쳤습니다.")
print(vip, "이 맹활약을 하였습니다.")
print("결국", winner, "가", loser, "를", score, "로 이겼습니다.")
print("===========================================")
```

➡️ **핵심**: 변수를 활용하면 **입력값이 바뀔 때마다 똑같은 템플릿으로 다른 결과물**을 만들어낼 수 있다 (자동 기사 생성, 자동 문서 생성의 기본 원리).
